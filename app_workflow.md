# App Workflow

## 1. Dashboard & Clients

### Dashboard
* Central management view.

### Clients
* **Unique UID** for each client.
* **One client can have multiple projects.**
* Client details are hard saved, but editable.
* **Example:**
  * Client: *Atom*
  * Action: Create Google Drive (GD) workspace for each client.
